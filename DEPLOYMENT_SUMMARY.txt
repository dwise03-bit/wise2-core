🚀 STEP-BY-STEP (Start on Your Local Machine)

STEP 1 - Generate SSH Key (1 min)
  $ ssh-keygen -t ed25519 -f ~/.ssh/wise2-deploy -N ""
  $ cat ~/.ssh/wise2-deploy.pub

STEP 2 - Add Public Key to Server (2 min)
  $ ssh dwise@173.208.147.165
  $ echo "PASTE_YOUR_PUBLIC_KEY" >> ~/.ssh/authorized_keys
  $ chmod 600 ~/.ssh/authorized_keys
  $ exit

STEP 3 - Test SSH (1 min)
  $ ssh -i ~/.ssh/wise2-deploy dwise@173.208.147.165
  $ exit

STEP 4 - Add GitHub Secrets (5 min)
  Go to: https://github.com/dwise03-bit/wise2-core/settings/secrets/actions
  
  Add 16 secrets (see GITHUB_SECRETS_QUICK_REFERENCE.md):
  • DEPLOY_HOST, DEPLOY_USER, DEPLOY_KEY
  • DOCKER_USERNAME, DOCKER_PASSWORD
  • DATABASE_URL
  • SENDGRID_API_KEY, SENDGRID_FROM_EMAIL
  • STRIPE_SECRET_KEY, STRIPE_PUBLIC_KEY, STRIPE_WEBHOOK_SECRET
  • OPENAI_API_KEY (optional), ANTHROPIC_API_KEY (optional)
  • JWT_SECRET, SESSION_SECRET

STEP 5 - Trigger Deployment (Automatic)
  Code is already pushed. Once GitHub Secrets are set:
  • GitHub Actions starts automatically
  • Builds Docker images (~3 min)
  • Pushes to Docker Hub (~2 min)
  • SSHs to production server
  • Runs docker-compose (~5 min)
  • Health checks run (~2 min)
  
  Total: ~8-12 minutes

STEP 6 - Verify Live (2 min)
  $ ssh -i ~/.ssh/wise2-deploy dwise@173.208.147.165
  $ docker ps
  
  Then visit:
  • https://wise2.net (Website)
  • https://api.wise2.net (API)
  • https://wise2.net/dashboard (Command Center)
  • https://wise2.net/studio (Creative Studio)
