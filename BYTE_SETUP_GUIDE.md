## ❓ TROUBLESHOOTING

### Device Not Responding
1. Check USB power connection
2. Wait 2 seconds for boot
3. Verify green LED is on
4. Try saying "Hey Byte" again

### Not Detecting Wake Word
1. Speak clearly and naturally
2. Move closer to device
3. Try "Hey Bot" as alternative
4. Check microphone isn't blocked

### Mouth Not Animating
1. Verify display is powered
2. Check screen brightness
3. Device may need reset
4. Power cycle device

### No WiFi Connection
1. Device works offline automatically
2. Will auto-connect to WISE2_DEMO
3. Check WiFi password
4. Device will retry every 3 seconds
