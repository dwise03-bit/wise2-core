# Cherry Count™ — Onboarding Checklist

## Pre-Launch (WISE² Team)

- [ ] Create tenant with vertical `retail_popup`
- [ ] Configure enabled modules
- [ ] Set up owner account and invite team
- [ ] Apply Cherry Count brand theme
- [ ] Seed demo inventory (optional)
- [ ] Verify API health check
- [ ] Test tenant isolation

## Client Onboarding (Week 1)

- [ ] Confirm brand assets and photography
- [ ] Walk through client presentation deck
- [ ] Document current inventory workflow
- [ ] List existing containers/bins with names
- [ ] Identify payment methods used
- [ ] Export existing customer list (if any)
- [ ] Schedule first pop-up event date

## Data Migration (Week 2)

- [ ] Load initial product catalog
- [ ] Create variants (sizes, colors)
- [ ] Assign storage locations
- [ ] Create containers with QR codes
- [ ] Import customer contacts
- [ ] Set low-stock thresholds

## Training (Week 3)

- [ ] Dashboard walkthrough
- [ ] Add product demo
- [ ] Create test pop-up event
- [ ] Pack Smart QR scanning demo
- [ ] Record practice sale
- [ ] Pop-Up Mode live walkthrough
- [ ] Cherry AI insights demo

## Launch (Week 4)

- [ ] Final inventory count verification
- [ ] First real pop-up event with Cherry Count
- [ ] Post-event closeout review
- [ ] Gather client feedback
- [ ] Schedule follow-up support call
