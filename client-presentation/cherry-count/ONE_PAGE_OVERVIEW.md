# Cherry Count™ — One-Page Overview

**Track It. Pack It. Profit.**

Cherry Count is the all-in-one inventory, sales, and pop-up management system built specifically for mobile retailers. Powered by the WISE² Business Operating System.

---

## What It Does

| Area | Capability |
|------|-----------|
| **Inventory** | Products, variants, photos, SKUs, locations, QR codes |
| **Pop-Ups** | Event planning, packing checklists, live mode |
| **Sales** | Multi-payment tracking, profit visibility |
| **Customers** | CRM with wishlists and demand signals |
| **Analytics** | Best sellers, trends, event performance |
| **Cherry AI** | Smart restock, packing, and trend insights |

---

## Who It's For

Mobile retailers, boutique owners, and pop-up vendors who need organization without sacrificing style.

---

## Technology

- Mobile-first responsive design
- Cloud-synced, secure, multi-device
- Enterprise infrastructure via WISE²
- AI-powered insights (read-only, safe)
