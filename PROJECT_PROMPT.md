# WISE² Project Prompt — Reference Replication Mode

Apply the repository's WISE² UI Constitution and agent rules.

Recreate the supplied/approved reference for the requested page or app screen as faithfully as technically practical. This is a reproduction/repair task, NOT a redesign task.

Before editing, inspect the current implementation, route, reusable components, real brand assets, fonts, imagery, and functionality that must remain intact. Identify the largest differences between the current render and the approved reference.

Then implement using the mandatory loop:

REFERENCE -> INSPECT -> BUILD -> RUN -> CAPTURE -> COMPARE -> CORRECT -> REPEAT -> VERIFY

Do not creatively reinterpret the layout. Do not replace supplied assets. Do not alter identity-locked people/logos/products/artwork. Do not modify visually correct unrelated sections.

Match the reference viewport first. Then verify representative mobile, tablet, and desktop sizes.

Do not report completion until you have run applicable technical checks and visually inspected the rendered result against the reference. Report remaining differences explicitly.
