# CJAYS Design System

## Theme

Dark-first, premium automotive instrumentation. Near-black is the working surface; deep navy separates operational regions; electric blue identifies navigation and primary actions; metallic gold marks brand moments and completion/value states. Decoration stays subordinate to data and workflow.

## Color

- Background: `#05080C`
- Surface: `#0C1219`
- Elevated surface: `#111A24`
- Divider: `#283442`
- Primary / electric blue: `#0878F9`
- Primary pressed: `#0561CC`
- Gold: `#D9A62E`
- Text: `#F6F8FA`
- Muted text: `#B4BFCA`
- Success: `#35C76F`
- Warning: `#F1B928`
- Error: `#FF5A64`

## Typography

Use the Android system sans family for speed and legibility. Headings are bold with compact line height; labels use medium weight; operational data uses tabular numerals where available. Avoid display fonts inside controls.

## Shape and Spacing

Use a 4dp spacing base. Primary rhythm: 8, 12, 16, 24, 32dp. Cards use 12–14dp corners, fields and buttons 10–12dp, and status badges full-pill. Minimum touch target is 48dp.

## Components

Primary actions use electric blue fills with white labels. Secondary actions use a strong divider-colored outline without shadow. Cards use surface separation and a subtle divider, never nested decorative cards. Status always combines text with color. Loading uses skeleton-like placeholders; empty states explain the next useful action.

## Navigation

Five bottom destinations: Dashboard, Jobs, Scan, Customers, More. Scan is raised visually and remains the dominant central action. Screen titles are direct and the current sync state remains visible.

## Motion

Use 150–220ms state transitions only. No decorative entrance choreography. Respect reduced-motion settings.
