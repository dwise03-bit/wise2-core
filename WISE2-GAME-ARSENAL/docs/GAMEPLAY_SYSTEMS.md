# Gameplay

Implemented: grid collision, movement, device fuse/capacity, blast propagation, wall blocking, destructible tiles, chain reactions, enemy pathfinding/evasion, damage, energy collection, blast-range upgrade, score, win/loss, reset and FPS/frame-time overlay.

Remaining: Godot port, Phaser adapter, audio/VFX event adapters, persistent saves, interpolation, remote/kick/throw devices and multiplayer. Configuration is exported in shared/round.mjs and injectable into Round.
