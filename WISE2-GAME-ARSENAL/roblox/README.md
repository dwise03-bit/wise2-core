# Roblox starter

Standalone Rojo + Luau first. Run `rojo serve` here and connect the Studio plugin. The minimal bootstrap initializes RoundService and the client. This is not yet profiles, inventory, matchmaking or VR. Add ProfileStore through an adapter after DataStore/session-lock tests. roblox-ts is optional when its compile step earns a clear benefit. Validate in Roblox Studio before use.
