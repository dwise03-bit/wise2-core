# WISE² Security

Shannon-powered AI-assisted security testing workspace.

## Authorization Policy

Testing is permitted only against systems that:
1. Are owned by the operator; or
2. Have explicit authorization for security testing.

Every Shannon engagement must have an engagement record before execution.

## Structure

engagements/  Authorization and engagement records
targets/      Approved target definitions
reports/      Final reports
evidence/     Scan evidence and artifacts
configs/      Shannon configurations
logs/         WISE² security logs
