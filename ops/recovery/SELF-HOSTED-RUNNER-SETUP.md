# WISE² self-hosted GitHub Actions runner bootstrap

**State:** workflow staged in GitHub; no runner installation or host changes confirmed.

## Security requirements
- Use only a **private** repository for this runner. Verify repository visibility before registering.
- Create a dedicated non-root Linux account for the runner. Do not give it unrestricted sudo or Docker socket access.
- Assign custom runner label `wise2-maintenance` in addition to default `self-hosted`, `linux`, `x64`.
- Restrict workflow changes and manual dispatch to trusted maintainers; protect the default branch.
- Never put Tailscale auth keys, GitHub registration tokens, or SSH private keys in the repository.
- Do not expose this runner to untrusted pull requests.

## Registration (one-time console access)
In GitHub repository Settings → Actions → Runners → New self-hosted runner, select Linux x64.
Follow the **current commands generated by GitHub** under the dedicated non-root account; the registration token is short-lived and must not be pasted into chat.
Use `--labels wise2-maintenance` when configuring, then install and enable the runner service per GitHub's instructions.
Verify the runner shows Online before triggering the workflow.

## Workflow
`.github/workflows/wise2-connectivity-audit.yml` runs **read-only** connectivity checks only.
It cannot apply changes until the runner is online and an explicitly scoped repair workflow is separately approved and reviewed.
The Pocket Node USB must be inventoried before any writing or flashing.
