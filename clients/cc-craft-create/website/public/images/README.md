## How to Add Images

1. Export/save images from your original files
2. Resize to recommended dimensions (optional - browser will scale)
3. Save as JPG or PNG
4. Place in this `/public/images/` directory
5. Refresh your browser to see them live

## Image Format Tips
- **JPG** - Better for photos (CC's headshot, product photos)
- **PNG** - Better for graphics with transparency
- **WebP** - Smallest file size (optional, for performance)

## File Size
- Keep images under 1MB each for fast loading
- Recommended: 200-500KB per image
