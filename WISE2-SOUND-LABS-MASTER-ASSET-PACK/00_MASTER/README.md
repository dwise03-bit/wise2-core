# WISE² Sound Labs — Master Asset Pack

Version 1.0.0. This pack is the canonical reusable asset library for the Sound Labs web, Android, iOS, Quest/XR, streaming, collaboration, and marketing surfaces.

The pack preserves existing WISE² identity artwork and the approved Sound Labs direction. Real MASCHINE hardware remains represented by the existing integration UI and is not replaced by invented hardware artwork.

Asset states are explicit: existing production assets are included; future platform exports are reserved in the folder structure and must not be treated as complete until real exports are added and verified.
