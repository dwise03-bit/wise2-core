DATABASE SCHEMA
================================================================================

Table: oauth_credentials
├─ Columns:
│  ├─ id (UUID, PRIMARY KEY)
│  ├─ user_id (UUID, FK → users.id, CASCADE)
│  ├─ provider (ENUM: google, github, microsoft)
│  ├─ access_token (TEXT)
│  ├─ refresh_token (TEXT, nullable)
│  ├─ token_type (VARCHAR, nullable)
│  ├─ scopes (TEXT, nullable - space separated)
│  ├─ expires_at (TIMESTAMP)
│  ├─ provider_account_id (VARCHAR, nullable)
│  ├─ account_name (VARCHAR, nullable - email)
│  ├─ is_active (BOOLEAN, default true)
│  ├─ last_used_at (TIMESTAMP, nullable)
│  ├─ error_message (VARCHAR, nullable)
│  ├─ created_at (TIMESTAMP, default NOW())
│  └─ updated_at (TIMESTAMP, default NOW())
├─ Indexes:
│  ├─ UNIQUE(user_id, provider)
│  ├─ (provider)
│  ├─ (expires_at)
│  └─ (is_active)
└─ Relations:
   └─ ManyToOne → User (cascade delete)

================================================================================
API ENDPOINTS
================================================================================

Booking Operations:
POST    /api/v1/bookings
  ├─ Create consultation booking
  ├─ Body: consultantEmail, title, startTime, endTime, timezone, ...
  └─ Returns: eventId, meetingLink, calendarLink

PUT     /api/v1/bookings/:eventId
  ├─ Reschedule/update booking
  ├─ Body: startTime, endTime, title, description
  └─ Returns: updated event details

DELETE  /api/v1/bookings/:eventId
  ├─ Cancel booking
  ├─ Query: consultantEmail, userEmail (optional)
  └─ Returns: success status

Calendar OAuth:
GET     /api/v1/bookings/calendar/auth-url
  ├─ Get OAuth authorization URL
  └─ Returns: authUrl

POST    /api/v1/bookings/calendar/callback
  ├─ Handle OAuth callback
  ├─ Body: code (from Google redirect)
  └─ Returns: connection status

GET     /api/v1/bookings/calendar/status
  ├─ Get connection status
  └─ Returns: connected, accountName, expiresAt, isExpiringSoon

POST    /api/v1/bookings/calendar/disconnect
  ├─ Disconnect Google Calendar
  └─ Returns: success status

GET     /api/v1/bookings/calendar/connected
  ├─ Check if Google Calendar connected
  └─ Returns: { connected: boolean }

================================================================================
ERROR CODES
================================================================================

UNAUTHORIZED (401)
├─ Google auth failed or revoked
└─ Solution: User reconnects via OAuth

FORBIDDEN (403)
├─ Permission denied on calendar
└─ Solution: Check calendar sharing settings

NOT_FOUND (404)
├─ Event/resource not found
└─ Solution: Event may have been deleted

RATE_LIMIT (429)
├─ Too many Google API requests
└─ Solution: Retry after delay with backoff

INVALID_TITLE (400)
├─ Event title is required
└─ Solution: Provide title in request

INVALID_TIMES (400)
├─ Start time must be before end time
└─ Solution: Verify time range

INVALID_TIME_RANGE (400)
├─ Times are invalid or overlapping
└─ Solution: Check booking duration

TIME_IN_PAST (400)
├─ Event must be at least 5 minutes in future
└─ Solution: Schedule for future date/time

MISSING_EVENT_ID (400)
├─ Event ID required to update/cancel
└─ Solution: Include eventId parameter

MISSING_REFRESH_TOKEN (400)
├─ Cannot refresh expired token
└─ Solution: User reconnects via OAuth

MISSING_GOOGLE_CREDENTIALS (400)
├─ Google credentials not configured
└─ Solution: Add environment variables

   imports: [GoogleCalendarModule]

5. USE SERVICE

       title: 'Consultation',
       startTime: new Date('2024-08-15T14:00:00Z'),
