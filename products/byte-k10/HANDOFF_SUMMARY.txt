================================================================================
                          CLIENT DEMO WORKFLOW
================================================================================

1. Plug K10 into USB
   → Green LED lights (device ready)

2. Say wake word ("Hi Telly" or "Jarvis")
   → Blue LED (device listening)

3. Say command ("Switch on", "Switch off", or "Hello")
   → Display shows recognized command
   → LED matches command (white, red, yellow)

4. Device returns to ready state
   → Green LED (waiting for next command)
   → Repeat from step 2!

Complete cycle: ~5-10 seconds
