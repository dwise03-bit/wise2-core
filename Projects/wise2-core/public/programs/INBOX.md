# Program Inbox

Use this as the capture point whenever either person discovers a program, tool, skill, integration, client request, or partially finished idea that is not yet organized.

## Triage checklist

1. Give it a clear name.
2. Decide whether it is a program, capability, experiment, or task.
3. Assign Daniel, Darren, or Joint ownership.
4. Create a program record if it is a program.
5. Add it to `PROGRAM_INDEX.md`.
6. Add the next action and date.

## Untriaged items

- Add newly discovered programs here with the date and source of discovery.
- Add client requests here before promising delivery.
- Add tools and skills here when their ownership or purpose is unclear.
