# WISE² Program Directory

The shared source of truth for programs created by Daniel and Darren.

This directory exists to prevent “I thought you knew” gaps while WISE² onboards clients. Every program gets one record, one accountable owner, a current status, and an explicit list of skills, tools, dependencies, and client-readiness gaps.

## Operating rule

If a program is discussed, prototyped, deployed, sold, or handed to a client, add it here before the work is considered organized. Unknown information is recorded as `TBD`; it is not silently inferred.

## Files

- `PROGRAM_INDEX.md` — fast directory of every known program.
- `PROGRAM_TEMPLATE.md` — copy this for each new program.
- `INBOX.md` — ideas, half-built programs, and discoveries that need triage.
- `CAPABILITY_MAP.md` — shared skills, tools, and reusable capabilities.
- `OPERATING_RULES.md` — lightweight update and handoff protocol.

## Status vocabulary

`idea` → `discovery` → `building` → `internal-ready` → `client-ready` → `active` → `paused` → `retired`

## Ownership vocabulary

Use `Daniel`, `Darren`, or `Joint`. The accountable owner is the person responsible for keeping the record current, even when both people contribute.
