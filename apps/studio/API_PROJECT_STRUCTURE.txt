ENVIRONMENT VARIABLES
====================

Required:
  JWT_SECRET              - Secret key for JWT signing
  NEXT_PUBLIC_APP_URL     - Frontend URL for CORS

Suno Integration:
  SUNO_API_KEY           - API key for Suno service

OBS Integration:
  OBS_HOST               - OBS machine hostname (default: localhost)
  OBS_PORT               - OBS WebSocket port (default: 4444)
  OBS_PASSWORD           - OBS connection password (optional)


TESTING
=======

With mock data (no external services):
  npm run dev
  curl http://localhost:3005/api/obs/scenes -H "Authorization: Bearer $TOKEN"

Full integration (with real services):
  1. Setup .env.local with API keys
  2. Start Suno service
  3. Start OBS on local machine
  4. npm run dev
  5. Test endpoints
