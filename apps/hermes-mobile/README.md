# HERMES mobile development
Expo SDK 54 starter. From this directory run npm install, then npx expo install --fix and npx expo-doctor. Android: npx expo run:android on an SDK-equipped host; for a debug APK run npx expo prebuild --platform android then cd android && ./gradlew assembleDebug. iOS: npx expo run:ios --device on the M4 with Xcode and valid signing. Configure a verified HTTPS OpenAI-compatible chat endpoint and scoped user token. Never use provider/admin keys. API compatibility, dependency resolution, signing, real assets and device tests are pending. Do not publish this development build.
