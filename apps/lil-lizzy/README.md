# Lil Lizzy & The BoomPopsters

Brand + shop preview for Lil Lizzy, the LED / Boom Tag, accessories, and the BoomPopsters universe.

## Run

From the repo root:

```bash
pnpm --filter @wise2/lil-lizzy dev
```

Open http://localhost:3028/lil-lizzy

## Notes

- Demo cart is local-only. Checkout is not live.
- Hardware specs on `/led-tag` match the Boom Tag prototype board (ESP32-S3, NFC, Bluetooth, USB-C).
