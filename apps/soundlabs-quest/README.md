# WISE² SoundLabs Live — Meta Quest

Native Meta Quest 3/3S spatial client for WISE² SoundLabs Live.

## Authority model

This app is a client of the existing WISE² LiveSession. It does not own session roles, project persistence, AI-provider credentials, Discord credentials, OBS credentials, or database access.

## Phase 1

- WISE² authentication boundary
- authoritative session snapshots
- realtime recovery
- MR/VR shared room shell
- participant presence
- chat
- Guided Influence polls
- creator/viewer role presentation
