## IF STUCK

**Xcode won't build?**
- Product → Clean Build Folder (Cmd + Shift + K)
- Try again: Cmd + R

**Code signing error?**
- Xcode → Settings → Accounts
- Add Apple ID
- Download certificates
- Try again

**Device not showing?**
- Unplug/replug USB
- Tap "Trust" on phone
- Wait 5 seconds
- Try Product → Destination again
