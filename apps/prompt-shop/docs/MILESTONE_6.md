# Milestone 6 — WT Hybrid

The recovered weighted Hybrid Builder now accepts both first-class source types in every required combination:

- System + System
- System + Subsystem
- Subsystem + Subsystem

Each of four available weighted slots can independently switch between System and Subsystem records. At least two active sources are required and total influence must equal exactly 100%.

## Generated Hybrid record

- Stable signature-based ID
- Hybrid name
- Typed and weighted parent sources
- Hybrid description
- Deduplicated Hybrid DNA
- Prompt foundation built from source DNA, not names alone
- Compatibility level, explanation, and shared-DNA evidence

Valid Hybrids can generate prompts and persist through the unified WT Favorites store with their source metadata and reusable prompt.
