# Milestone 4 — WT Docs

The existing System detail screen is now a complete WT Docs System view. Together with the Milestone 2 Subsystem view, the application exposes the required documentation surfaces for both first-class record types.

## System view

- Name and Category
- Description and Core DNA
- Visual DNA
- Use Cases
- Subsystems
- Related Systems
- Flagship, Hybrid, Prompt, and documentation status badges
- Prompt, Favorite, and Hybrid actions

## Subsystem view

- Name and parent System
- Description and Visual DNA
- Use Cases
- Related Systems and Subsystems
- Hybrid and Prompt actions
- Documentation status badges

Fields awaiting authoritative content display explicit empty states instead of fabricated data.
