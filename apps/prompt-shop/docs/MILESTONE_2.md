# Milestone 2 — Subsystem documentation

Every normalized Subsystem now opens an individual WT Docs view from its parent System page.

The view displays:

- Subsystem name and parent System
- Individual description
- Category and readiness badges
- Visual DNA
- Use Cases with an honest undocumented state
- Related Systems and Subsystems with honest undocumented states
- Prompt generation action
- Parent-System Hybrid action

Navigation remains internal state at this milestone. The route manifest documents the future URL shape without introducing a routing dependency before the baseline production build is available.
