# Milestone 11 — Results / Asset Library

Completed video jobs are automatically converted into versioned `wt-assets` records containing the provider identifiers, source System and Subsystem, prompt, aspect ratio, duration, timestamps, and output URL.

The Results tab provides playable previews, text search, type and provider filters, prompt inspection and reuse, open/download actions, and explicit deletion. Milestone 11 intentionally uses local browser persistence; Milestone 12 will move user ownership and durable records behind authentication.
