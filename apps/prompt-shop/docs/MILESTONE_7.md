# Milestone 7 — WT Prompt Engine

The production Prompt Engine combines user intent with normalized WISE TOUCH System and Subsystem DNA.

## Inputs

- System
- Optional Subsystem
- Subject or concept
- Mood
- Output Type
- Aspect Ratio
- Target Engine
- Additional Instructions

## Outputs

Supported production directions include Image, Video, Cover Art, Poster, Branding, Editorial Visual, and Storyboard. Engine guidance is available for Universal prompts, Claude, Gemini, Flow, Midjourney, and a provider-neutral Other target.

Generated prompts include actual Core DNA, Subsystem direction, and deduplicated Visual DNA. Users can edit via their source inputs, preview the complete prompt, copy it, or save it through WT Favorites.
