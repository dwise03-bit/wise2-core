# Milestone 3 — WT Search

WT Search queries both Systems and Subsystems across names, categories, descriptions, Core DNA, Visual DNA, Use Cases, tags, and legacy Subsystem names.

Results are explicitly labeled `System` or `Subsystem`; Subsystem results include their parent System and open directly into their individual WT Docs view.

Available filters:

- Category
- Flagship
- Fully Documented
- Favorites
- Hybrid Ready
- Prompt Ready

No record is currently marked flagship or fully documented, so those filters correctly return an empty state. Favorites filtering reflects the recovered System-only Favorites behavior until Milestone 5 extends the persistence model.
