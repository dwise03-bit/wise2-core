# Routes

Milestone 0 preserves the recovered working app exactly as an internal tab-driven experience.

`routeManifest.js` records the intended routable surfaces for Milestone 1:
- `/directory`
- `/favorites`
- `/hybrid`
- `/prompt`
- `/video`
- `/results`
- `/system/:slug`

Do not introduce URL routing until the baseline is confirmed and data normalization is underway.
