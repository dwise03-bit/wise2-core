================================================================================
                           QUICK START
================================================================================

USING THE SYSTEM:

1. Sound Lab appears in Creative Studio → Sound Lab

2. Timeline Tab (default view)
   - See all clips (blue=generated, green=recorded)
   - Play/Stop/Undo/Redo/Export buttons
   - Drag clips to reposition

3. Generation Tab
   - Fill in Suno prompt (genre, mood, description)
   - Click "Generate"
   - View queue progress
   - Click "Add" to add completed music to timeline

4. Mixer Tab
   - See all tracks with channel strips
   - Adjust volume, pan, mute per track
   - Monitor peak levels

5. Effects Tab
   - Select track/clip
   - Click "+ Add Effect"
   - Choose type (EQ, Reverb, Delay, Compression, Distortion)
   - Adjust parameters
   - Enable/disable or remove effects

KEYBOARD SHORTCUTS:
  Cmd+Z / Ctrl+Z = Undo
  Cmd+Shift+Z / Ctrl+Shift+Z = Redo
  Space = Play/Pause

                          HOOK API QUICK REF
================================================================================

useClips:
  • clips.getClips() → Map<string, ClipData>
  • clips.updateClip(clipId, updates)
  • clips.addGeneratedClip(trackId, buffer, generation, name, startTime)
  • clips.addClip(trackId, buffer, name, startTime)
  • clips.removeClip(clipId)
  • clips.moveClip(clipId, newStartTime)
  • clips.trimClipStart/End(clipId, amount)
  • clips.setFadeIn/Out(clipId, duration)
  • clips.duplicateClip(clipId, offset)
  • clips.splitClip(clipId, splitTime)

useClipEffects:
  • effects.initializeChain(clipId, trackId)
  • effects.getChain(clipId) → ClipEffectsChain
  • effects.addEffect(clipId, type, params) → effectId
  • effects.updateEffect(clipId, effectId, params)
  • effects.toggleEffect(clipId, effectId)
  • effects.removeEffect(clipId, effectId)
  • effects.setVolume(clipId, 0-1)
  • effects.setPan(clipId, -1 to +1)
  • effects.toggleMute(clipId)
  • effects.undo() / redo()
  • effects.getHistoryInfo()

audioEffects utilities:
  • createEQNode(ctx, frequency, gain, Q)
  • createLowShelfEQ(ctx, gain)
  • createHighShelfEQ(ctx, gain)
  • createReverbNode(ctx, wet)
  • createDelayNode(ctx, time, feedback, wet)
  • createCompressorNode(ctx, threshold, ratio, attack, release)
  • createDistortionNode(ctx, drive)
  • createEffectsChain(ctx, effects[], volume, pan) → { input, output, nodes }
  • processAudioBufferWithEffects(offlineCtx, buffer, effects, volume, pan)
  • dbToLinear(db) / linearToDb(linear)

================================================================================
                         INTEGRATION POINTS
================================================================================

1. CLIP GENERATION
   App/Page → SoundLabEnhanced → handleSunoGenerate()
   → fetch(/api/suno/generate)
   → pollGenerationStatus()
   → addGeneratedClipToTimeline()
   → clips.addGeneratedClip()
   → effects.initializeChain()

2. PLAYBACK
   Play button → handlePlayTimeline()
   → for each clip:
      → get effects.getChain(clipId)
      → createEffectsChain(audioContext, chain.effects, volume, pan)
      → source → chain → destination
   → audio plays through speakers

3. EXPORT
   Export button → handleExport()
   → OfflineAudioContext.startRendering()
   → for each clip:
      → processAudioBufferWithEffects()
      → mix into master
   → encodeWAV()
   → download()

4. EFFECTS EDITING
   Effects Tab → User adjusts slider
   → effects.updateEffect()
   → Hook state updates
   → Component re-renders
   → Next playback uses new settings

================================================================================
                         IMPLEMENTATION NOTES
================================================================================

HOOK SEPARATION:
  • useClips = Clip state only
  • useClipEffects = Effects state only
  • useClipInteraction = Clip editing (drag, trim, select)
  • Each maintains independent undo/redo history

AUDIO CONTEXT:
  • Web Audio API (native browser audio)
  • useRef to persist AudioContext across renders
  • OfflineAudioContext for export (no UI blocking)

STYLING:
  • Tailwind CSS throughout
  • Custom CSS variables for theme colors
  • Responsive layout (flex/grid)
  • Dark theme optimized

STATE MANAGEMENT:
  • useState for UI state (activeTab, isPlaying, etc.)
  • useCallback for memoized event handlers
  • No external state management needed
  • All state lives in components and hooks

================================================================================
                           KNOWN LIMITATIONS
================================================================================

CURRENT:
  • Reverb uses basic convolver (no impulse response file)
  • Delay/Reverb tails cut off at export end time
  • No time-stretching (change tempo without pitch)
  • No MIDI support (audio clips only)
  • Limited to 2-channel stereo mix
  • No multi-band processing

FUTURE ENHANCEMENTS:
  • Load custom impulse responses for reverb
  • Automation (keyframe effect parameters)
  • Preset effects (save/load combinations)
  • VST/AU plugin support
  • MIDI file import/export
  • Surround sound (5.1, 7.1)
  • Real-time waveform analysis
