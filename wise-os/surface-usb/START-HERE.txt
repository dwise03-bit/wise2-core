WISE² LINUX OS — INSTALL INSTRUCTIONS (SURFACE LAPTOP 4 / INTEL / 16 GB)

This USB contains an Ubuntu 24.04 amd64 installer and the WISE² workstation
setup. It is not yet a remastered WISE² live OS image.

ON THE SURFACE
---------------

1. Boot the USB. Plug it in, boot into UEFI/boot menu. If Secure Boot is
   on, allow Microsoft & 3rd-party CA signatures when prompted.

2. Pick the right boot entry:
     WISE2 Linux OS - Start Ubuntu installer     <- normal path
     WISE2 Linux OS - Safe graphics installer     <- if the display fails
     WISE2 Linux OS - Boot diagnostics            <- verbose messages, debug only

3. Install Ubuntu — PICK THE CORRECT DISK.
   The installer's disk list shows both this external USB drive AND the
   Surface's own internal disk. Check the size and/or model name before
   confirming: install to the EXTERNAL drive's 247.5 GB Linux partition,
   not the internal disk. Installing to the internal disk instead of this
   USB will not boot the way these instructions expect, and nothing will
   actually land on this drive. These scripts do not partition any disk;
   do not assume the 247.5 GB Linux partition is empty without checking.

4. Reboot into the installed Ubuntu and connect to the internet.

5. Open a terminal in wise2-branding: open the WISE2INST volume in Files,
   open wise2-branding, right-click blank space, choose Open in Terminal.

6. Run the installer:

     bash START-WISE2.sh --no-ollama-model

   Drop --no-ollama-model to also pull the local AI model during install
   (slower). This runs, in order:
     wise2-setup.sh        Docker, Node, Ollama, Tailscale, VS Code, dirs
     (Surface kernel driver, only if a Surface Laptop 4 is detected)
     install-wise2-theme.sh   GNOME Shell / GDM / Plymouth branding
     install-dashboard.sh     WISE² Command Center web dashboard
     install-agent-reach.sh   Agent-Reach research channel diagnostics
     install-shannon.sh       Shannon AI pentester (local Ollama, zero cost)

   If it stops partway, the error and line number print to the terminal
   and are logged to ~/.local/state/wise2/install.log — fix that specific
   thing and rerun; the script is safe to rerun.

7. Reboot. If the blue Surface MOK enrollment screen appears: Enroll MOK,
   Continue, Yes; password: surface (QWERTY layout — matters if the
   keyboard mapping looks wrong).

8. Log in. WISE² Command Center should auto-start. If the GNOME Shell top
   bar theme doesn't show up immediately, log out/in once — it needs the
   User Themes extension enabled, which can need a session restart.

9. Sign in to Tailscale:  sudo tailscale up

VERIFY IT WORKED
-----------------

  systemctl status wise2-command-center   dashboard service
  uname -r                                 should mention "surface" if the
                                            kernel driver applied
  Dashboard:  http://127.0.0.1:3080

DASHBOARD
----------

the original map/incidents/IMP-assistant panels, and a Security Center
view wired to Shannon (scan controls, live terminal, findings,
vulnerability breakdown). Sidebar items without a built feature yet

Network, Settings) show an explicit "not yet implemented" placeholder
instead of silently doing nothing.
