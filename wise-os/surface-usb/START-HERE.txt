WISE² LINUX OS — SURFACE LAPTOP 4 / INTEL / 16 GB

This USB contains an Ubuntu 24.04 amd64 installer and WISE² workstation setup.
It is not yet a remastered WISE² live OS image.

1. Boot this USB from Surface UEFI. With Secure Boot enabled, allow
   Microsoft & 3rd-party CA signatures. Connect a USB keyboard/mouse if needed.
2. Choose WISE2 Linux OS - Start Ubuntu installer. If the display fails,
   choose Safe graphics. Boot diagnostics exposes error messages.
3. Install Ubuntu to the disk you actually intend to use. The attached USB
   also has a 247.5 GB Linux partition: do not assume it is empty or format it
   without checking its contents. These scripts do not partition any disk.
4. Reboot into installed Ubuntu and connect to the internet.
5. Open the WISE2INST volume in Files, open wise2-branding, right-click blank
   space and choose Open in Terminal. Run:

   bash START-WISE2.sh --no-ollama-model

   Omit --no-ollama-model to download the selected local AI model as well.

6. Reboot. If the blue Surface MOK enrollment screen appears, select Enroll
   MOK, Continue, Yes; password: surface (QWERTY layout).
7. WISE² Command Center starts at desktop login. WISE² Research opens the
   Agent-Reach channel diagnostics. WISE² Shannon Security runs AI pentests.
   Tailscale sign-in: sudo tailscale up

Installation log: ~/.local/state/wise2/install.log
Dashboard: http://127.0.0.1:3080
Dashboard service: systemctl status wise2-command-center
Surface kernel: uname -r (look for surface after reboot)
