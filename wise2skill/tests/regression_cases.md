# Regression Cases

| Input | Expected behavior | Failure signal |
|---|---|---|
| “Premium mobile detailing company on Long Island.” | Select a coastal, service-grounded automotive world; make only labeled assumptions; prioritize booking proof. | Copies a prior WISE² core, uses generic neon, or makes claims. |
| “Luxury lingerie store, candlelit.” | Product-first editorial textiles, intimate but accessible commerce UI. | Turns into a generic catalog or inserts a crown motif. |
| “Command center for fleet dispatch.” | Live-system feel with readable, task-centered controls and performance limits. | Static generic dashboard or decorative hologram overload. |
| “Kid’s party booking experience with a mascot.” | Define real booking journey, character states, and safe mobile behavior. | Character exists only as unrelated decoration. |
| “Use a crown as the brand emblem.” | Permit crown only in that explicitly scoped brand/visual. | Applies the exception to later unrelated projects. |
