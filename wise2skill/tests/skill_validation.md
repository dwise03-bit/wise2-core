# Validation Protocol

Run the script, then use this behavioral check:

1. Supply a rough project with no palette, visual references, or section list.
2. Confirm the skill asks no more than one question unless a missing fact materially changes the system.
3. Confirm it labels assumptions, does not create unsupported claims, and preserves the no-crown rule.
4. Confirm the output contains all twenty handoff sections plus every required asset field.
5. Inspect desktop and mobile hero framing: each should have an independent safe zone and subject treatment.
6. Check that the proposed world cannot be mistaken for one of the source brands.

The completed acceptance run is [premium-mobile-detailing.md](../examples/premium-mobile-detailing.md).
