# Source-Derived Reference Patterns

These are analytical signatures from the supplied source collection, not visual templates. Do not copy their names, motifs, or scene concepts into an unrelated brief.

| Source implementation | Signature | Reusable lesson |
|---|---|---|
| WISE² Cloud — Living Core | Midnight energy aperture, absorb/transform system story | Turn an abstract platform into a visible causal environment. |
| WISE TOUCH™ Prompt Shop | Laser orange construction world with a foreman mascot | Let a useful real-world metaphor govern navigation, hierarchy, and character behavior. |
| Supplied by Krystle | Botanical, premium supply/product atmosphere | Make sustainability commercial and tactile, not childish or rustic by default. |
| Krystle Dumpling Universe | Glossy companion and party/booking world | Connect character states to real actions such as booking, customization, and drops. |
| Rose & Lace Society | Dark editorial textiles and candlelight | Give commerce product-first elegance without generic catalog staging. |

| SteveWillDoIt concept | Aviation, cars, runway scale | Use spectacle only when it supports the brand’s lifestyle/action proposition. |
| WISE² Future Foundry | Idea-to-system ecosystem | Make services a progressive path with connected proof. |

| WISEALITY™ | Multiple realities with shared rules | Let worlds vary while preserving a shared system of UI, transitions, and story. |

## Cross-project system

The collection repeatedly requires a master visual board, desktop hero, mobile 9:16 treatment, section scenes, material references, motion/transition concepts, UI safe zones, responsive crop notes, exclusions, implementation notes, asset naming, and QA. Its durable principle is **one coherent environment per brand, with UI designed for that environment**.
