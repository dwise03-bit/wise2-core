# Asset Manifest

Use one row per asset. IDs follow `[project]-[section]-[asset]-[variant]-v01`; examples: `harbor-hero-master-desktop-v01`, `harbor-hero-master-mobile-v01`.

| Priority | Asset ID | Name / purpose | Section | Ratio / target resolution | Desktop / mobile | Static / animated | Method | Dependencies | Status |
|---|---|---|---|---|---|---|---|---|---|
| MUST HAVE |  |  |  |  |  |  |  |  | planned |

Create separate MUST HAVE, SHOULD HAVE, and OPTIONAL groups. A generation method should state photograph, 3D/render, image generation, video generation, compositor, or code—not just “AI.”
