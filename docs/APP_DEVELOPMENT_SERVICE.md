### 3. **Cross-Platform Development**
Single codebase for iOS & Android with React Native.

**Technologies**:
- React Native framework
- TypeScript for type safety
- Expo for rapid development
- Native modules when needed
- Shared component library

**Use Cases**:
- MVP & rapid prototyping
- Tight timelines & budgets
- MVP-to-native migration path
- Code sharing between platforms
- Faster iteration cycles

**Limitations**:
- Some device-specific features may require native code
- Performance-critical apps use native
- Complex animations better in native
