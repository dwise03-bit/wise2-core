# Cherry Count™ — Product Definition

**Brand:** Cherry Count™  
**Tagline:** Track It. Pack It. Profit.  
**Platform:** Powered by the WISE² Business Operating System  
**Vertical:** `retail_popup`  
**Status:** MVP in development (as of 2026-08-29)

---

## What We Are Building

Cherry Count is a premium, mobile-first operating system for mobile pop-up retailers. It gives boutique owners one beautiful place to manage inventory, plan pop-up events, pack smart, track sales, nurture customers, and get AI-powered business insights.

Cherry Count is the **client-facing brand**. WISE² is the **technology foundation** underneath.

---

## Target User

Mobile retailers who:
- Sell at pop-ups, markets, and events
- Carry inventory across bins, racks, and storage
- Need to know what's selling, what's low, and what to pack
- Want a system that feels built for their business, not generic ERP software

---

## Core Problems Solved

| Problem | Cherry Count Solution |
|---------|----------------------|
| Spreadsheets everywhere | Unified inventory with photos, SKUs, variants |
| Packing confusion | Smart packing lists + QR container scanning |
| Unknown sell-through | Live sales tracking during events |
| Forgotten customer requests | CRM with wishlists and demand signals |
| No profit visibility | Sales dashboard with margin tracking |
| Manual event closeout | Event workflow: pack → live → return → analyze |

## Signature Features

1. **Pop-Up Mode** — Entire event in your pocket: checklist, live sales, bin locations
2. **Pack Smart** — QR-coded containers (bins, racks, totes) with instant contents lookup
3. **Cherry AI** — Read-only insights: restock, packing, trends, event summaries
4. **Customer Love** — Track sizes, colors, wishlists, and repeat demand
