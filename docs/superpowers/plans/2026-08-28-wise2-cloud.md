# WISE² Cloud Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Launch `cloud.wise2.net` as a recurring-revenue WISE² reseller-hosting storefront with Stripe billing, automated provider provisioning, customer status, and admin operations.

**Architecture:** Extend the existing NestJS/Next.js WISE² Core rather than introducing a second platform. Stripe confirms recurring payment; the Cloud module persists order state and queues provider-neutral provisioning through Redis; provider adapters create isolated customer hosting accounts outside WISE² Core.

**Tech Stack:** NestJS 10.2, TypeORM 0.3.17, PostgreSQL 16, Redis 7, Next.js, Stripe, Jest, Docker/Traefik, provider REST/WHM API.

**Spec:** `docs/superpowers/specs/2026-08-28-wise2-cloud-design.md`

## Global Constraints

- Preserve the locked WISE² Cloud / Piff City black, electric-blue, steel/chrome, and white visual system.
- WISE² Core is the system of record; customer hosting workloads remain isolated from WISE² Core containers/database/Redis.
- Reuse the existing Stripe billing integration and webhook surface.
- Provider credentials remain server-side secrets only.
- Provisioning must be asynchronous and idempotent.
- Initial public plans: Starter $19/month, Business $39/month, Pro $59/month.
- Contractor/Managed plans do not become purchasable until their WISE² entitlements exist.
- Production uses TypeORM migrations, not auto-sync.

---

## File Structure

Create `packages/api/src/v1/cloud/` for Cloud domain logic, entities, DTOs, provider interfaces, queue orchestration, and tests. Modify the existing billing webhook only to hand confirmed subscription events to Cloud. Add public Cloud pages under `apps/website/app/cloud/` and customer/admin Cloud views under the existing dashboard surfaces. Keep provider implementations under `packages/api/src/v1/cloud/providers/` so changing suppliers does not change order logic.
