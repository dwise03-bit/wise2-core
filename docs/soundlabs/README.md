# WISE² Sound Labs

Sound Labs is the WISE² music-production surface spanning the browser, Android wrapper, local bridge, MASCHINE control, REAPER transport, WISE² GPT, collaboration, streaming, and Quest handoff.

The browser demo route is `/sound-labs`. The controller app lives in `apps/sound-labs-ui`; the local bridge is `services/sound-labs/bridge` on port 8788.
