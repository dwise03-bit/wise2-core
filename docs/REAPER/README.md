## Recommended First Coding Session

Build M0 Foundation and M1 Product Shell only.

Do not start by wiring multiple live commercial providers.

Use mock/fixture providers first.

## Core Product Invariants

- Business Health and Digital Execution are separate.
- UNKNOWN is not zero.
- Major findings cite evidence.
- Long-running audits use workers.
- Providers are swappable.
- External messages require approval.
- Pricing is never invented by AI.
- Prospect history survives client conversion.
