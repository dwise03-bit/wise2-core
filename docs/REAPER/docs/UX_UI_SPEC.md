# REAPER V1 — UX/UI DESIGN SYSTEM + SCREEN SPECIFICATION

## Experience Goal

REAPER should feel like:
BUSINESS INTELLIGENCE
+ STRATEGIC COMMAND CENTER
+ FIELD AUDIT TOOL
+ PREMEDITATED SUCCESS ENGINE

Not:
generic CRM
generic admin dashboard
crypto exchange
overloaded cyberpunk HUD
gamer interface
spreadsheet with lipstick

## Visual Direction

REAPER COMMAND INTELLIGENCE

Dark luxury intelligence interface.
Near-black foundation.
Graphite cards.
Electric accents.
Structured grid.
Data-dense but calm.

Primary accent: toxic-electric signal green.
Electric blue: evidence/data.
Amber: warning.
Red: critical.
Violet: Premeditated Success.

## Core UI Principle

Decision first.
Evidence second.
Detail third.

Every screen should answer:
WHAT IS HAPPENING?
HOW GOOD IS IT?
HOW CERTAIN ARE WE?
WHY DOES IT MATTER?
WHAT SHOULD WE DO NEXT?

## Motion

Fast, precise, controlled.
No giant bouncing cards.
Audit running may use moving scan line / node pulse.
Score load max ~500–700ms.
Respect reduced motion.

## UX Invariants

- Unknown data never looks like failure.
- Confidence always accessible.
- Strengths are strategic assets, not decoration.
- Business Health visually separate from Digital Execution.
- Opportunity distinct from quality.
- Client language separated from internal intelligence.
